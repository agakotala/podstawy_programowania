# Java w IntelliJ IDEA — zmienne, typy danych i operatory

Projekt jest przygotowany do pracy razem z instrukcją `lab_02_v2`.

## Wymagania

- IntelliJ IDEA,
- JDK 25,
- bez Maven i Gradle.

Po otwarciu projektu upewnij się, że IntelliJ korzysta z JDK 25. Jeśli IntelliJ poprosi o wskazanie SDK, wybierz zainstalowane JDK 25 w ustawieniach projektu.

## Jak pracować

1. Otwórz projekt w IntelliJ IDEA.
2. Upewnij się, że folder `src` jest oznaczony jako **Sources Root**.
3. Otwieraj przykłady w podanej kolejności.
4. Przeczytaj komentarz na początku pliku.
5. Spróbuj przewidzieć wynik programu.
6. Dopiero potem uruchom klasę zielonym przyciskiem przy `main`.
7. Porównaj wynik z opisem w kodzie i instrukcji.
8. W zadaniach uzupełniaj miejsca oznaczone `TODO`.
9. Fragmenty celowo błędnego kodu są zapisane w komentarzach, aby cały projekt nadal mógł się kompilować.
