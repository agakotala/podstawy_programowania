JAVA — MATERIAŁ DO INSTRUKCJI

1. Otwórz projekt w IntelliJ IDEA.
2. Ustaw JDK 25 jako SDK projektu, jeśli IntelliJ o to poprosi.
3. Zacznij od src/block1/Example01Hello.java.
4. Czytaj przykłady po kolei.
5. Pliki z przykładami mają komentarze wyjaśniające zagadnienie i przewidywany wynik.
6. W zadaniach szukaj komentarzy TODO lub polecenia do samodzielnej analizy.
7. Celowo błędny kod jest zapisany w komentarzach, aby cały projekt nadal się kompilował.
